# EMAGIAKU GLASS OS 27

Developed by EMAGIAKU.TEAM - Based on Arch Linux

Questo repository distribuisce gli **aggiornamenti** di EMAGIAKU GLASS OS (EG Update).

## Hai installato EMAGIAKU GLASS OS 27 (ISO del 10/11/2026)?
Una sola volta, apri **Konsole** e scrivi:

```
curl -fsSLo /tmp/eg.sh https://raw.githubusercontent.com/EMAGIAKU/EMAGIAKU-GLASSOS-27/main/installa-eg-update.sh && sudo bash /tmp/eg.sh
```

Da quel momento gli aggiornamenti arrivano con una **notifica** ("Aggiornamento disponibile").
Puoi anche aprire **EG Update** dal menu.

Ogni aggiornamento e' firmato digitalmente da EMAGIAKU.TEAM: se la firma non e' valida, il sistema non
installa niente.
